# Data provenance

Every number and place on the map is one of three kinds. This file says which, and is honest about what has **not** been independently checked.

| Kind | Meaning | Where it lives |
|---|---|---|
| **Live** | fetched from a named provider at runtime; nothing is stored | most of `src/services/*.ts` (OpenSky, AISStream, USGS, NASA FIRMS, GDACS, IODA, UNHCR, World Bank, OWID/Ember, OSM Overpass, GPSJam, …) |
| **Snapshot** | a committed copy of a real dataset, regenerated by a script; each file records its source, reference year and retrieval date | `public/data/pipelines-trunk.geojson` (OSM, ODbL) via `scripts/build-pipelines.mjs`; `src/data/chokepoints-portwatch.json` (IMF PortWatch) via `scripts/build-chokepoints.mjs` |
| **Curated** | typed into the repo by hand from the sources named below | the files in the table below |

The rule in `CLAUDE.md` is that a curated entry must be a real, identifiable thing traceable to a named source. This audit checks that the *claim* of a source is stated and honest. **It did not re-verify each entry against its source** — that is the open work, and the "Known weaknesses" column says where a skeptical reader should look first.

## What would close the gaps

In order of payoff for a skeptical reader:

1. **Per-entry citations** for the datasets that carry numbers (`oilgas`, `tradeStats`, `military` personnel, `chokepoints`): add `source` and `asOf` fields to the types and populate them, dropping any entry that can't be cited.
2. **Replace curated lists with free live/keyless sources** where one exists — IMF PortWatch for ports, the WRI Global Power Plant Database (CC-BY) for power, Energy Institute / OWID for oil and gas, World Bank for trade shares.
3. **Show provenance in the UI**: surface "curated, approximate, as of …" in the popup for curated layers, as the pipelines layer already shows its OSM attribution.

## Keeping this file honest

`tests/policy.test.ts` fails if a curated dataset file listed above is renamed or removed without this document being updated, or if a header reintroduces the words "complete" / "comprehensive" for a hand-curated list.
